# Behavior Guidelines

## Plan Mode Constraints
- When in Plan Mode (Shift+Tab), you must act under "Maximum Brevity" constraints.
- Do not output block overviews or conversational preambles.
- Keep plan lists strictly limited to a single level of bullet points.
- Descriptions for any given step must not exceed 10 words. 
- Use brief fragments instead of complete sentences (e.g., "Fix auth token refresh" instead of "We need to fix the auth token refresh mechanism inside the repository").
